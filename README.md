# LanGhost

**Local Network Reconnaissance Tool**

Aggressive device discovery, deep network intelligence, port scanning and monitoring — built for Android with a premium tactical design.

## Status

🚧 Early development (v0.1)

### Planned for v0.1
- Full Wi-Fi network information
- Device discovery (ARP + ICMP + mDNS)
- Detailed device cards (IP, MAC, Vendor, Hostname, OS estimation)
- Basic port scanner
- Nicknames, tags and notes for devices
- Premium dark tactical UI
- Tablet-optimized layout

## Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Coroutines + Flow
- Minimum SDK 26
